# RCCG Spring of Life — implementation plan

## Milestone 1: foundation and cinematic hero
- Next.js App Router, TypeScript, Tailwind, GSAP + ScrollTrigger, Lucide and DM Sans.
- Preserve Figma node 16:2 direction: navy navigation, three-line welcome, red CTA, Sunday invitation, three quick links.
- Responsive navigation, accessible information dialogs, video playback control and reduced-motion/data-saving fallbacks.
- Use clearly identified temporary stock media; no unverified address, times, contact details or stream links.
- Validate lint, TypeScript, production build and responsive browser behavior.

## Next milestones
1. Editorial church introduction, events and sermons with approved content.
2. Image-led ministries, Kingdom Projects UI, testimonies and full footer.
3. Backend design, database decision, secure admin and Paystack (separate authorization/phase).

## Scope and open decisions
Backend and payment integration are not part of this milestone. No Supabase. PostgreSQL is mentioned in the brief, but the database selection remains unconfirmed. Real church logo, photography, film, location, service schedule, prayer contact and media channels are still needed.
